# 迷宮リバーシ / Reversi Delve

**リバーシなのに、迷宮を下りていくローグライク。** 1 階 = 1 局のリバーシ。勝つと宝石の石か遺物を 3 つから 1 つ選んで、次の階へ。灯（命）が尽きるまで、どこまで深く下りられるか。

- Bundle ID：`com.enludus.daily.012`（枠 012）
- 題材：監督の指示（daily-ideas #32、予定 #19 の 11/17 分）「リバーシ × ローグライク」。今日の Issue：daily-ideas #33
- iPhone（Duo の内側の大きな画面では、盤を大きく・右に番人と石の袋と深さの地図）。iOS 18 以降
- 「オセロ」は登録商標なので、名前・説明・画面では「リバーシ」と書く

## だれの・どう使うか
- リバーシは好きだが、CPU と同じ盤で打ち続けるのに飽きた人。ローグライク（Slay the Spire など）は好きだが、カードの覚えることが多くて重い人
- 1 階は 6×6（深い階は 8×8）の小さな盤で 2〜4 分。通勤やすきま時間に 1〜3 階ずつ下りられ、中断すると続きから遊べる

## 遊び
| | |
|---|---|
| 盤 | 階ごとに穴（置けない・列が途切れる）と金のはめこみ（×2 点）が、左右・上下対称に並ぶ。1〜6 階は 6×6、7 階から 8×8 |
| 宝石の石（無料 4 種） | 錨（返されない）・炎（横一列を返す）・時（どこにでも置け、2 手後にまわりを返す。返されると止まる）・金（3 点ぶん） |
| 宝石の石（Pro 3 種） | こだま（もう 1 手）・幽霊（穴の上に置ける）・彗星（縦一列を返す） |
| 遺物 7 種 | 隅の礎石・光のプリズム・石袋・つるはし・金の鉱脈・灯籠・残り火 |
| 番人 13 人 | 階ごとに決まった打ち方：多く返す／隅を好む／少しだけ返す／1 手先の盤の形を読む／2 手先まで読む。深い階ほどでたらめが減り、錨の石を使う |
| 灯 | 3 つで始まる（最大 5）。負けると 1 つ消え、同じ階を新しい盤でやり直す。尽きたら探索の終わり |
| 階の帯 | 苔の回廊（1〜3）→ 水晶の洞（4〜6）→ 溶岩の炉（7〜9）→ 星の底（10〜12、Pro）→ 深淵（13〜、Pro） |

### 難しさの調整（Python で試した）
特殊な石なしで、人に近い打ち方（1 手先の形を読む・でたらめ 15〜35%）と番人を 150 局ずつ打たせた勝率：6×6・多く返す（でたらめ 50%）80〜83%、隅を好む 63〜73%、1 手先を読む 36〜57%、8×8・2 手先を読む 25〜44%。ここに宝石の石と遺物と灯 3 つが足されるので、上手な人が 9 階に届くかどうか、の難しさにした（`Dungeon.spec`）。

## 毎日開く理由
1. **今日の迷宮**：日付から作る種で、だれが潜っても同じ盤・同じ報酬。1 日 1 回。その日の最深が残り、続けた日数が灯で並ぶ
2. **最深の記録と図鑑**：宝石 7・遺物 7・番人 13 を集める。階の帯の地図に、届いた深さが灯る
3. **探索の記録と共有カード**：この 7 日の今日の迷宮の深さ（下へ伸びる棒）、深さのカードを画像で共有

## 世界観
**このアプリでは〔地下の迷宮の石と灯り〕が〔盤と画面〕になり、〔リバーシの石〕が〔カットした宝石〕になる。**
- 主役：八角形にカットした宝石の石（自作の Shape。外形・テーブル・カットの線・光の当たり）。あなた＝月長石、番人＝黒曜石、特殊な石は宝石の色の縁と印
- 脇役：彫った石の板の盤（Canvas。上と左が明るく下と右が暗い縁・石材の粒・穴・金のはめこみ）、灯（しずく形の炎）、深さの地図、入口のアーチと下りる階段
- 帯ごとに石材と灯りの色が変わる：苔の回廊（深い緑の石・琥珀の灯）、水晶の洞（藍の石・水色の灯）、溶岩の炉（焦げた石・橙の灯）、星の底（紺の石・金の灯）
- 前日までの 9 本（ネオンのライブハウス・水彩の空・木のテーブルの城・夜の水面・夜明けの空・工事現場・夜の地下鉄・町中華）と違う：暗い石壁の地・階ごとに変わる灯りの色・銅版の題字（Copperplate）・八角形の宝石が主役
- 画面はダークに固定（地下の迷宮が世界で、灯りが主役のため）

### 参考にしたもの（ui-reference）
- ローグライクのゲーム全般（Slay the Spire の階の地図・報酬を 3 つから選ぶ場面）：仕組みの型だけを借りた。名前・絵・キャラは使わない
- 借りたもの：①階を抜けた直後に、札が時間差で起き上がって 3 つ並ぶ選択の場面 ②縦に下りる階の地図（いまの階が灯る）③探索のまとめで大きな数字（届いた深さ）を主役にする

## 手応えの表
| できごと | 動き | 振動 | 音（端末の中で作る） |
|---|---|---|---|
| 押す | マスが 0.88 倍に沈む・石のボタンが沈む | selection | 小さな「カチ」 |
| 置く（1 つ成功） | 石が 1.4 倍から弾んで落ちる | impact light | 硬い「カツ」 |
| 返る・連鎖 | 置いた所から近い順に 55ms ずつ、縦の軸で回って面が入れ替わる（途中 1.18 倍）。5 個以上で重い振動 | 5 個以上で impact heavy | ガラスの「チン」が返るたびに高くなる |
| 炎・彗星・時の石 | 列に光の帯が走って消える・弾けたマスが光る | heavy | 低い「ボン」 |
| 失敗（番人に隅を取られた・負けた） | 盤が横に揺れる（減衰） | error | 低い「ドン」 |
| 完了（階を抜けた） | 報酬の札が 0.12 秒ずつ起き上がる | success | 4 音の上がるチャイム |
| 場面の切れ目（階に入る） | 「地下 n 階」と番人の名前の札 | — | 下りていく音 |
動きを減らす設定では、めくり・弾み・揺れ・札の起き上がりを止める。

## デモで見せる流れ（起動引数 `-demo`、約 18 秒）
1. 迷宮の入口（ホーム）→ 今日の迷宮の 1 階へ
2. 炎の石を選んで隅に置く → 横一列の黒曜石が光の帯で一気に返る
3. どちらも置けなくなり階を抜ける → 宝石・遺物・灯の札が起き上がり、1 つ選んで 2 階へ

## 作らなかったもの
- オンライン対戦・ランキング（サーバーを持たない）。今日の迷宮は同じ盤なので、深さは共有カードで比べる

- XcodeGen（`project.yml`）。ビルドとテストは GitHub Actions（daily-actions の再利用ワークフロー）
